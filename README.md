# 2027 수시 일정판

2027학년도 대입 수시모집 진학지도를 위한 일정판입니다.

- **수시 일정 달력** — 1차(1단계) 합격자 발표, 면접·구술고사, 서류 마감, 최종 발표를 달력에 입력하고 D-day로 확인합니다.
- **면접 지도 시간표** — 교사 주간 시간표에서 공강 시간을 표시하고, 그 시간에 지도 학생을 배정해 면접 지도 계획표를 만듭니다.
- **CSV 내보내기** — 일정과 지도 계획을 엑셀·구글 스프레드시트에서 열 수 있습니다.

## 저장 방식

이 저장소에는 화면(`index.html`)만 들어 있습니다. 입력한 일정과 학생 정보는
**별도의 비공개 저장소**에 있는 `data.json` 파일에 저장됩니다.

페이지를 열고 오른쪽 위 **저장소 설정**에서 다음을 입력하세요.

| 항목 | 값 |
| --- | --- |
| GitHub 계정 | 비공개 데이터 저장소의 소유자 |
| 데이터 저장소 이름 | 예: `susi-2027-data` |
| 브랜치 | `main` |
| 파일 경로 | `data.json` |
| 액세스 토큰 | 아래에서 만든 PAT |

### 액세스 토큰 만들기

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**
2. Repository access → 데이터 저장소만 선택
3. Permissions → Repository permissions → **Contents: Read and write**
4. 발급된 토큰을 페이지의 **저장소 설정**에 붙여넣기

토큰은 입력한 브라우저에만 저장되며 이 저장소에는 올라가지 않습니다.
토큰을 등록하지 않은 사람에게는 빈 화면만 보입니다.
